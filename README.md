# Control Mensual (control de gastos)

App de un solo archivo (`index.html`) para registrar gastos e ingresos del hogar y del consultorio. Los datos quedan en el navegador de quien la usa, no en este repositorio. Autor: Gonzalo Gabriel Pereira.

- `index.html`: toda la app.
- `PROYECTO.md`: reglas de trabajo, hoja de ruta de 100 mejoras, pendientes y registro. Leer antes de tocar nada.
- `tests.py`: pruebas con Playwright.

Una tarea programada diaria implementa las mejoras y sube cada versión a la rama `main`.
